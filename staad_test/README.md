# Files to test in STAAD.Pro CONNECT Edition

These files were generated by the application's current default sidebar
settings: 40 m width, 60 m length, 6.5 m eave height, 1:10 roof slope,
7.5 m bays, ISMB 400 columns, ISMB 350 rafters, E350 steel and IS800 LSD.
They are a **test building**, not a model of your actual project.

Open **PEB_CONNECT_2D_v2.std** first. It is the middle transverse frame with its
tributary loads. Then open **PEB_CONNECT_3D_v2.std** to test the full building
geometry and the new purlin/girt end releases in STAAD's Specifications tab.
The v2 material is named **STEEL**. Its selected steel grade is **E350** (yield
strength 350 MPa), which is recorded in the material strength and design data.
In each file, run STAAD analysis and note the first input error,
all warnings, number of joints/members/load cases, and whether the analysis
and design commands complete. In particular, share any errors about Indian
table sections, material definitions, load envelopes or CHECK CODE.

The app's own STD parser read both v2 files back successfully. This checks file
structure, but does not prove Bentley accepts or solves them. Full automatic
crane, wall, code-based seismic and detailed wind actions remain outside these
test inputs. See [the option audit](../docs/SIDEBAR_STAAD_AUDIT.md).

Regenerate the same files from the workspace root with
`python -m scripts.create_connect_test_files`.
